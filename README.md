is not affiliated with or endorsed by the OBS Project.

## ExcelVisus

ExcelVisus is a customizable native audio visualizer source. It includes
spectrum bars, mirrored and radial layouts, waveform and dot styles, gradients,
rainbow colors, rounded caps, neon glow, peak markers, and flexible FFT/audio
response controls.

- [Source, documentation, and build instructions](ExcelVisus/README.md)
- Platform: Windows x64
- Tested with OBS Studio 32.2.2

Prebuilt downloads are published separately on the repository's Releases page.
