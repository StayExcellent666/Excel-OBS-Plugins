# Excel Streaming Plugins

Independent third-party streaming tools by StayExcellent666. This repository
is not affiliated with or endorsed by the OBS Project.

## ExcelVisus

ExcelVisus is a customizable native audio visualizer source. It includes
spectrum bars, mirrored and radial layouts, waveform and dot styles, gradients,
rainbow colors, rounded caps, neon glow, peak markers, and flexible FFT/audio
response controls.

- [Source, documentation, and build instructions](ExcelVisus/README.md)
- Platform: Windows x64
- Tested with OBS Studio 32.2.2

Prebuilt downloads are published separately on the repository's Releases pages.

## ExcelFortuna

ExcelFortuna is a native Twitch Channel Points giveaway wheel connected to
ExcelProtocol. It provides a live entrant counter, server-authoritative winner
selection, animated wheel reveal, Twitch chat announcement, neon styling,
confetti, and safe offline preview controls.

- [Source, setup, security notes, and build instructions](ExcelFortuna/README.md)
- Platform: Windows x64
- Tested with OBS Studio 32.2.2
